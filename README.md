# jdbc_database_system
Movie Rating &amp; Recommendation System  MS SQL DB for users, movies, genres, tags, ratings &amp; watchlists. Features: extreme rating block (TR_BLOCK_EXTREME), trend status auto-update (TR_UPDATE_MOVIE_TREND), user rewards (SP_REWARD_USER_), personalized recommendations, thematic specialization &amp; user profiling (curious/focused/undefined). JDBC classes.
